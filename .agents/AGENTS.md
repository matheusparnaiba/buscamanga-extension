## Regras de Comunicação e Desenvolvimento

- Para cada alteração de código realizada, sempre forneça automaticamente (sem precisar pedir) um resumo/summary para o Git em português (PT-BR), contendo o título do commit e a descrição detalhada das mudanças feitas.
- Toda atualização em qualquer fonte (extensão) deve alterar o número da versão dela (version bump) no respectivo `pbconfig.ts`, inclusive atualizando o número da versão na tabela do `README.md`.
- Antes de iniciar qualquer alteração, edição ou trabalho no código, sempre pergunte ao usuário para qual versão do Paperback (ex: v0.8 ou v0.9) a modificação deve ser direcionada.
